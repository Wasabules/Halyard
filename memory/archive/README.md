# memory/archive — states, not findings

A note in `memory/` records something **learned**. A note here records something
that was **true at a moment**: a milestone reached, a build repaired, a path
that worked in May 2026. The repository's own rule says progress does not belong
in the knowledge base, and these predate that rule.

They are archived rather than deleted for one reason: knowing what was tried,
and when, is what stops it being tried a second time. Nine of them describe the
**libdatachannel/WebRTC path abandoned on 2026-05-06** - that branch is dead, and
its history is the only thing that explains why the code still carries a
`legacy/` directory.

**Do not act on anything in here.** `KB.md` says what holds today.
